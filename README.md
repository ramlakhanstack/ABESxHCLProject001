Heart Failure Clinical Records – EDA
# About Project
This project performs Exploratory Data Analysis (EDA) on the Heart Failure Clinical Records dataset to understand patient data, identify patterns, and analyze clinical features associated with death events.
# Dataset
- Records: 299 patients
- Features: 13 clinical attributes
- Target: DEATH_EVENT
- Source: UCI Machine Learning Repository
# Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
  # Analysis
- Age distribution
- Death event analysis
- Mean, median, min & max
- Ejection fraction analysis
- Serum creatinine analysis
- Data visualization using graphs
  # Objective
To explore clinical data, identify trends, and understand relationships between patient characteristics and death events.
# Disclaimer
This project is for educational and data analysis purposes only, not for medical diagnosis.
